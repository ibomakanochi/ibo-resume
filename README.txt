DANIELLA YSABELLE IBO — RESUME WEBSITE

Files:
- index.html: main website
- style.css: responsive design
- script.js: mobile menu and project modal

HOW TO USE:
1. Open index.html in a browser to preview.
2. Replace the photo placeholders with your own professional picture.
3. Replace the email, LinkedIn, and GitHub placeholders with your actual links.
4. Update the Seminars / Trainings section with your real completed seminars.
5. Upload the folder to your preferred static hosting service, or use the HTML/CSS structure as the basis for a mobile website builder.

ASSIGNMENT ALIGNMENT:
- Header with Home / About / Contact navigation
- Home landing page with brand and call-to-action
- Two-column grid layout with image + text + button
- About/Resume two-column layout with personal photo and text content
- Roboto font
- Resume section headings are 14px and bold; regular body text is 12px
- Footer uses a three-area grid, navigation, social buttons, and Copyright 2026
- Responsive mobile layout
